## 📂 HATUA 1: Kuweka kwenye GitHub

### 1.1 Unda Repository GitHub
1. Ingia [GitHub.com](https://github.com)
2. Bofya **"New Repository"**
3. Jina: `teacher-document-system`
4. Description: `Advanced Document Management System for Teachers`
5. Chagua **Public** (ili iweze kuonekana)
6. Bofya **"Create Repository"**

### 1.2 Upload Files kwenye GitHub
```bash
# Initialize git (kama haujaanza)
git init

# Add all files
git add .

# Commit files
git commit -m "Initial commit: Complete Teacher Document Management System"

# Add GitHub remote
git remote add origin https://github.com/YOUR_USERNAME/teacher-document-system.git

# Push to GitHub
git branch -M main
git push -u origin main
```

## 🌐 HATUA 2: Deployment kwenye Vercel

### 2.1 Unda Database (Vercel Postgres - BURE!)
1. Ingia [Vercel.com](https://vercel.com)
2. Ingia kwa akaunti yako
3. Kwenda **Storage** → **Create Database**
4. Chagua **Postgres**
5. Jina: `teacher-docs-db`
6. Region: **Washington D.C.** (kwa haraka zaidi)
7. Bofya **Create**

### 2.2 Deploy Application
1. Kwenye Vercel dashboard, bofya **"New Project"**
2. Import repository yako ya GitHub: `teacher-document-system`
3. **Framework Preset**: Other
4. **Root Directory**: `./` (default)
5. Bofya **Deploy**

### 2.3 Sanidi Environment Variables
Baada ya deployment, ongeza environment variables:

1. Kwenda **Project Settings** → **Environment Variables**
2. Ongeza variables hizi:

```env
# Database (Vercel Postgres)
POSTGRES_URL=your_vercel_postgres_url_here

# JWT Secret (generate random string)
JWT_SECRET=your_super_long_random_secret_key_minimum_32_characters

# Admin Account
ADMIN_EMAIL=admin@teachersystem.com
ADMIN_PASSWORD=Admin123!@#

# Node Environment
NODE_ENV=production

# File Upload Settings
MAX_FILE_SIZE=52428800
UPLOAD_PATH=./uploads
ALLOWED_FILE_TYPES=pdf,doc,docx,txt,ppt,pptx,xls,xlsx,jpg,jpeg,png,gif

# Security Settings
BCRYPT_ROUNDS=12
RATE_LIMIT_WINDOW=15
RATE_LIMIT_MAX_REQUESTS=100
```

### 2.4 Connect Database
1. Kwenye Vercel project, kwenda **Storage**
2. Connect database uliyounda: `teacher-docs-db`
3. Copy **POSTGRES_URL** na iweke kwenye Environment Variables

### 2.5 Initialize Database
1. Kwenye Vercel project dashboard
2. Kwenda **Functions** → **Edge Functions**
3. Au tumia Vercel CLI:

```bash
# Install Vercel CLI
npm i -g vercel

# Login
vercel login

# Deploy na setup database
vercel env pull .env.local
npm run setup-vercel
```

## 🔧 Troubleshooting
